# Frontend code example lab

Use this lab to run the HTML, CSS, React, and Bootstrap snippets from LexForge cards. Run one card at a time in a scratch directory. You need a browser and Python 3. The React and Bootstrap sections also use Node.js and npm.

## HTML and CSS

Create a scratch directory and start a local server.

```sh
lab_dir=$(mktemp -d "${TMPDIR:-/tmp}/lexforge-frontend.XXXXXX")
cd "$lab_dir"
python3 -m http.server 8000 --bind 127.0.0.1
```

Keep the server running. In another terminal or an editor, save the card as `index.html` in the scratch directory. If the card starts with `<!doctype html>`, copy it as the whole file. Otherwise, paste its markup inside the body of this page. If the snippet starts with a `<style>` block, put that block in the head.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>LexForge snippet</title>
</head>
<body>
  <!-- Paste the card markup here. -->
</body>
</html>
```

Open [the local lab](http://127.0.0.1:8000/). To compare responsive states, change the viewport width in browser DevTools and reload. For `source set`, also change the emulated device pixel ratio.

For an image card that references `blue.svg`, `blue-large.svg`, or `green.svg`, create the sample files next to `index.html` before opening the page.

```sh
printf '%s\n' '<svg xmlns="http://www.w3.org/2000/svg" width="48" height="48"><circle cx="24" cy="24" r="16" fill="steelblue"/></svg>' > blue.svg
printf '%s\n' '<svg xmlns="http://www.w3.org/2000/svg" width="96" height="96"><circle cx="48" cy="48" r="32" fill="steelblue"/></svg>' > blue-large.svg
printf '%s\n' '<svg xmlns="http://www.w3.org/2000/svg" width="48" height="48"><circle cx="24" cy="24" r="16" fill="seagreen"/></svg>' > green.svg
```

## Bootstrap

Run this command from the scratch directory.

```sh
npm install --no-save bootstrap@5.3.9 sass@1.93.3
```

Use the HTML page above. Add these tags to the head before any card styles or scripts. This lets the theming example override Bootstrap's defaults and gives the card scripts access to `bootstrap` and Popper. [Bootstrap JavaScript documentation](https://getbootstrap.com/docs/5.3/getting-started/javascript/)

```html
<link rel="stylesheet" href="./node_modules/bootstrap/dist/css/bootstrap.min.css">
<script src="./node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>
```

For a Sass card, paste the HTML portion into the page and the SCSS portion into `lab.scss`. Compile it, then replace the Bootstrap stylesheet link with `<link rel="stylesheet" href="./lab.css">`. Dart Sass may report deprecations from the Bootstrap 5.3 Sass sources. [Bootstrap Utility API](https://getbootstrap.com/docs/5.3/utilities/api/)

```sh
./node_modules/.bin/sass --load-path=node_modules --quiet-deps lab.scss lab.css
```

## React

Use a separate scratch directory if you want to keep the Bootstrap lab installed. If you switch directories, stop the old server with Ctrl+C and start it in the new directory. Start with the HTML page from the first section. Run the React setup command from your scratch directory.

```sh
npm install --no-save react@19.2.0 react-dom@19.2.0 esbuild@0.25.12
```

Save the card as `Demo.jsx`. Create `main.jsx` with the following code, then replace the page body contents with the HTML shown below.

```jsx
import { createRoot } from 'react-dom/client';
import Demo from './Demo.jsx';

createRoot(document.querySelector('#root')).render(<Demo />);
```

```html
<div id="root"></div>
<script src="./demo.js"></script>
```

Build, then reload the lab. The development build enables the checks shown by the Strict Mode and Profiler examples. Open the browser console to see the Strict Mode render count.

```sh
./node_modules/.bin/esbuild main.jsx --bundle --jsx=automatic --outfile=demo.js
```

### Server rendering and hydration

For `server rendering`, save the card as `server.jsx` and run the following commands. The terminal displays the generated HTML.

```sh
./node_modules/.bin/esbuild server.jsx --bundle --platform=node --jsx=automatic --outfile=server.cjs
node server.cjs
```

For `hydration`, save the two sections of the card as `Demo.jsx` and `client.jsx`. Use the following `server.jsx` and run the same server commands. Replace the empty root element in your HTML with the full line printed by the server command and keep the `demo.js` script below it. Bundle `client.jsx` in place of `main.jsx`, then reload and click **Save reservation**. The client attaches React to the HTML generated by the server. [React hydrateRoot reference](https://react.dev/reference/react-dom/client/hydrateRoot)

```jsx
import { renderToString } from 'react-dom/server';
import Demo from './Demo.jsx';

console.log('<div id="root">' + renderToString(<Demo />) + '</div>');
```

```sh
./node_modules/.bin/esbuild client.jsx --bundle --jsx=automatic --outfile=demo.js
```
